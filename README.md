# 四川省公务员考试时政刷题库

一个针对四川省公务员考试的时政选择题库网页，支持练习模式、模拟考试、错题集和错题重练。

## 在线访问

开启 GitHub Pages 后，可通过以下链接访问：

`https://你的用户名.github.io/你的仓库名/`

## 功能介绍

- **顺序练习**：逐题练习，做错自动收录到错题集，即时查看解析
- **模拟考试**：30 分钟限时考试，答题卡快速跳转，交卷后查看分数与解析
- **错题集**：汇总所有答错的题目，可查看解析或移除
- **错题重练**：仅练习错题，答对后自动从错题集中移除
- **本地进度保存**：使用浏览器本地存储，刷新页面不丢失进度

## 题库内容

共 20 道精选题目（持续更新中），**严格聚焦 2025 年—2026 年时政热点**，题型设计参照四川省公务员考试真题风格：

**全国时政 10 题**：
- 2026年两会：2025年GDP（140.19万亿元，增长5%）、2026年目标（4.5%—5%）
- 赤字率4%、赤字规模5.89万亿元、超长期特别国债规模持平
- "十五五"开局之年、抗战胜利80周年、西藏自治区成立60周年
- 2025年航天发射92次（商业航天50次）、国家航天局设立商业航天司
- 天问二号小行星探测（2025年5月29日发射）
- 城镇新增就业1267万人、失业率5.2%

**四川时政 10 题**：
- 成渝双城经济圈经济总量超9万亿元（占全国6.5%）
- 2026年GDP目标5.5%左右、"十五五"开局之年
- 省委十二届八次全会（审议通过"十五五"规划建议）
- 省长施小琳作2026年政府工作报告
- 四川省2026年公务员考试报名时间（2025年10月30日—11月5日）

**题型特点**：侧重具体数字精确考查、政策文件名称对应、会议时间与议题匹配、正确表述判断（多选项混合真假），干扰项设置贴近真实考试难度。

## 每周自动更新说明

本仓库已配置 GitHub Actions，每周一自动检查并尝试更新题库。你可以在 `.github/workflows/update-quiz.yml` 中查看和修改更新规则。

## 本地使用

直接用浏览器打开 `index.html` 即可使用，无需服务器。
